# 2D Game

A small 2D game prototype written in C++ with SDL2. It demonstrates a game loop, sprite rendering, and player and enemy characters. Use the arrow keys to change the player's facing direction.

## Requirements

- A C++17 compiler
- Make
- SDL2 and SDL2_image development libraries, including `sdl2-config`
- A Unix-like shell (Linux, macOS, or WSL)

## Build and run

From the project root:

```sh
make
./build/mon-jeu
```

To remove the generated files, run `make clean`.
